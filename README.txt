Название игры: «Три дня на ферме»
Версия билда: 1.0
Разработчик: Иксанов Дмитрий Михайлович
Целевая ОС: Веб-формат (ПК)

Инструкция запуска
Откройте любой современный браузер (Google Chrome, Microsoft Edge, Яндекс.Браузер, Firefox).

Перейдите по ссылке на игру: https://whyxsnowx.github.io/farm_game/

Дождитесь загрузки главного меню.

Нажмите кнопку «Играть».

(Игра работает без установки дополнительного ПО. Для игры требуется подключение к интернету).

Управление
W, A, S, D — движение фермера.

E — взаимодействие (посадка, полив, сбор, набор воды).

1 — купить семена в магазине.

2 — купить пугало (защита от ворон).

ESC — пауза.

Известные ограничения:

1.Музыка включается только после первого клика мышью по экрану (политика браузеров).

2.При первом запуске игра может грузиться 5–10 секунд из-за скачивания ресурсов.
